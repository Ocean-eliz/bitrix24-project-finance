# Как использовался ИИ и как проверялся результат

Тестовое задание выполнено с использованием ИИ как инструмента ускорения разработки, но не как «чёрного ящика».

## Где использовался ИИ

- декомпозиция требований на сущности `Project`, `Employee`, `Category`, `Transaction`;
- черновая структура FastAPI API и SQLite-схемы;
- черновая HTML/CSS/JS-реализация интерфейса;
- подбор граничных случаев для финансовых расчётов;
- сверка способа запуска приложения внутри iframe Битрикс24 с официальной REST-документацией.

## Что проверено и скорректировано вручную

1. **Деньги не хранятся в float.** Суммы переводятся в целое количество копеек, чтобы избежать ошибок двоичной арифметики.
2. **Финансовые показатели считаются на backend.** Клиент только отображает результат.
3. **Деление на ноль обработано.** При нулевых расходах рентабельность не вычисляется и отображается как `—`.
4. **Отрицательная прибыль поддерживается.** Рентабельность также может быть отрицательной.
5. **Обязательные статьи создаются автоматически** при первом запуске БД.
6. **Проверена совместная модель данных:** к одному проекту можно привязать несколько сотрудников, а данные хранятся централизованно на сервере.
7. **Интеграция с Битрикс24 не мешает локальной проверке:** внутри портала используется `BX24.init` / `user.current`, вне портала приложение работает в demo-режиме.

## Фактически выполненные проверки

```text
pytest -q
4 passed
```

Дополнительно выполнен API smoke-test:

- создан сотрудник;
- создан проект;
- сотрудник добавлен в проект;
- добавлен доход 100 000,00 ₽;
- добавлен расход 25 000,50 ₽;
- получены показатели:
  - доходы: 100 000,00 ₽;
  - расходы: 25 000,50 ₽;
  - прибыль: 74 999,50 ₽;
  - рентабельность: 299,99%.

Также выполнены `python -m compileall` и `node --check app/static/app.js`.

## Что я бы усилил для production

- серверная OAuth-проверка пользователя Битрикс24;
- роли и права доступа по проектам;
- PostgreSQL вместо SQLite при высокой конкурентной нагрузке;
- аудит изменений и мягкое удаление операций;
- пагинация списка сотрудников Битрикс24 для больших порталов;
- интеграционные/e2e-тесты в CI.
